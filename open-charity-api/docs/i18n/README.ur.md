# اوپن چیریٹی API اسٹینڈرڈ (OCAS)

> خیراتی اداروں کے عطیات کے APIs کے لیے ایک کھلا، غیر جانبدار معیار۔
> اس طرح ڈیزائن کیا گیا ہے کہ کوئی بھی خیراتی ادارہ — چھوٹی مسجد، بین الاقوامی NGO، فوڈ بینک، یا پناہ گاہ — کسی بھی ڈویلپر کی بنائی ہوئی کسی بھی ایپلیکیشن کے ساتھ، دنیا میں کہیں بھی، ضم ہو سکے۔

---

## یہ پروجیکٹ کیوں موجود ہے

اگر آپ نے کبھی ایسا سافٹ ویئر بنانے کی کوشش کی ہو جو خیراتی اداروں سے بات کرتا ہو، تو شاید آپ اسی مسئلے سے ٹکرائے ہوں گے جس سے زیادہ تر ڈویلپرز ٹکراتے ہیں: **کوئی متفقہ معیار موجود نہیں ہے۔** جو خیراتی ادارے عطیات قبول کرنے کا کوئی پروگرامی طریقہ پیش کرتے ہیں، وہ سب اپنے اپنے انداز میں ایسا کرتے ہیں۔ اور زیادہ تر تو کچھ بھی پیش نہیں کرتے — وہ تیسرے فریق کے پلیٹ فارمز پر انحصار کرتے ہیں (JustGiving، Donorbox، GoFundMe، Enthuse) جن میں سے ہر ایک کا اپنا انٹرفیس، اپنا ڈیٹا ماڈل اور اپنی فیس ہے۔

اس بکھراؤ کی قیمت ہے:

- وہ ڈویلپر جو اپنی ایپ میں "خیراتی ادارے X کو عطیہ کریں" کا فیچر شامل کرنا چاہتا ہے، اسے N مختلف نظاموں سے انضمام کرنا پڑتا ہے۔
- وہ خیراتی ادارے جو ادائیگی شدہ پلیٹ فارمز کے متحمل نہیں ہو سکتے، ٹیکنالوجی کی دنیا سے باہر رہ جاتے ہیں۔
- چھوٹے اسلامی اور کمیونٹی پر مبنی ادارے وسیع تر سافٹ ویئر ماحول میں تقریباً نظر نہیں آتے۔
- Gift Aid، باقاعدہ عطیات، زکوٰۃ کی درجہ بندی، ٹیکس رسیدیں — یہ معیاری تصورات ہر بار از سرِ نو (اور خراب طریقے سے) بنائے جاتے ہیں۔

**OCAS** اس مسئلے کو حل کرنے کی ایک کوشش ہے۔ یہ ایک مفت اور کھلی تفصیل ہے جسے کوئی بھی خیراتی ادارہ اپنا کر اپنے عطیات، سبسکرپشنز، مہمات، رسیدیں اور ٹیکس رعایت کے اعلانات ایک معیاری شکل میں پیش کر سکتا ہے۔ پھر کوئی بھی ایپلیکیشن کسی بھی OCAS کے مطابق خیراتی ادارے کے ساتھ ایک ہی کوڈ پاتھ استعمال کرتے ہوئے ضم ہو سکتی ہے۔

یہ پروجیکٹ جان بوجھ کر:

- **وینڈر کے حوالے سے غیر جانبدار ہے۔** کسی Stripe، PayPal یا کسی مخصوص پروسیسر سے بندھا ہوا نہیں۔
- **سطحی طور پر مذہبی اور نظریاتی طور پر غیر جانبدار ہے۔** سیکولر فوڈ بینک اور مسجد دونوں کے لیے یکساں کام کرتا ہے۔
- **جہاں ضروری ہو، مذہبی طور پر باخبر ہے۔** زکوٰۃ، صدقہ، صدقہ جاریہ، وقف، للہ، فدیہ، کفّارہ، قربانی، عقیقہ کے لیے فرسٹ-کلاس سپورٹ — Gift Aid، 501(c)(3)، DGR، ANBI اور دیگر ٹیکس رعایت کی اسکیموں کے ساتھ ساتھ۔
- **خود میزبانی کے قابل ہے۔** ہر خیراتی ادارہ اپنے سرورز پر OCAS چلا سکتا ہے۔ کوئی مرکزی اتھارٹی نہیں۔ کوئی لازمی مرکز نہیں۔

## بڑی تصویر

OCAS ایک وسیع تر کوشش کا پہلا پروجیکٹ ہے: **سماجی طور پر فائدہ مند سافٹ ویئر کے لیے کھلے، مشترکہ معیارات، پروٹوکولز اور انفراسٹرکچر** کی تعمیر، جس میں خاص توجہ مسلم ڈویلپرز، ماہرینِ تعلیم اور کمیونٹیز کو کھلے عام تعاون کرنے کے قابل بنانے پر ہے — جبکہ کام بذاتِ خود ہر ایک کے لیے دستیاب رہتا ہے۔

عزائم یہ ہیں کہ یونیورسٹیاں، محققین اور پروفیسر جن کے پاس اسلامی مالیات، اخلاقی کمپیوٹنگ، حلال ادائیگی کے راستوں یا منصفانہ تقسیم کے بارے میں نظریات ہیں، حوالہ جاتی تطبیقات شائع کر سکیں جنہیں کوئی بھی ڈویلپر مناسب انتساب کے ساتھ تعمیر کر سکے۔ Pull requests، RFC مسودے اور تعلیمی مقالے سب خوش آمدید ہیں۔

اگر آپ کچھ ایسا بنا رہے ہیں جو اسلامی مالیات سے باخبر ہو، کمیونٹی پر مرکوز ہو، یا اقدار کے ساتھ ہم آہنگ ہو، اور آپ نے خود کو پہیہ از سر نو ایجاد کرتے پایا ہے، تو یہ وہ جگہ ہے جہاں آپ پہیہ لا کر دوسروں کو استعمال کرنے دیں۔

## اسلامی عطیات کی اقسام جو سپورٹ شدہ ہیں

| قسم | معنی |
|---|---|
| `zakat` | فرض سالانہ عطیہ، 8 شرعی مدوں میں سے کسی پر |
| `sadaqah` | عمومی رضاکارانہ خیرات |
| `sadaqah_jariyah` | جاری/مسلسل ثواب کی خیرات |
| `waqf` | اوقاف، مستقل غیر منقولہ |
| `lillah` | اللہ کے لیے، Gift Aid کے قابل نہیں اگر شرائط پوری نہ ہوں |
| `fidya` | تلافی (مثلاً چھوٹے روزے) |
| `kaffarah` | کفّارہ |
| `qurbani` / `udhiyyah` | عید الاضحیٰ کی قربانی |
| `aqiqah` | بچے کی پیدائش کی قربانی |
| `interest_purification` | ربا کی صفائی، زکوٰۃ کے طور پر نہیں دی جا سکتی |

تفصیلات اور ضروری میٹا ڈیٹا کے لیے `docs/islamic-considerations.md` دیکھیں۔

## مقصد

یہ کوئی تجارتی پروڈکٹ نہیں ہے۔ کوئی کمپنی نہیں ہے۔ کوئی فیس نہیں ہے۔ اس کا مقصد ایک معیار ہے — ایسا معیار جو ہر کسی کا ہے اور کسی کا نہیں — تاکہ خیراتی ادارے اور ڈویلپرز نقصاندہ مالکانہ گیٹ ویز کے بغیر مل کر کام کر سکیں۔

اگر یہ مفید لگے تو اپنایئے۔ اگر کوئی غلطی نظر آئے تو ٹھیک کیجیے۔ اگر کچھ کمی ہو تو شامل کیجیے۔
